# arm_assembly_greenhouse_monitor
Bare-metal ARM Cortex-M4 environmental logger in pure Thumb-2 Assembly. Highlights include an O(log N) Triple Segment Tree for real-time statistical queries, a 6-state event-driven FSM with software debouncing ,Event Latches, and a bitwise sliding-window POV multiplexer for a 5x5 LED matrix. Zero OS, pure hardware-level optimization.
